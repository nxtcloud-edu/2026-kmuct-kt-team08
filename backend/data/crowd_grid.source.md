## 가공 방법

1. citydata 실측 지점값을 역거리 가중(IDW, power=2)으로 격자 중심에 배분
2. 실행 시각의 time_slot(11시)은 **실측 기반**
3. 나머지 23개 time_slot 은 실측값을 기준점으로 삼아 일중 변동 프로파일(`DIURNAL`)로 환산한 **모델값**
4. `crowd_score` = population / 전체 최대 population × 100

## 한계

- citydata 는 지정 지점만 실시간 제공하며 임의 좌표·격자 조회를 지원하지 않습니다.
- 실측 지점 좌표는 역·지역 중심의 근사값입니다.
- 11시를 제외한 시간대는 모델 추정치이므로, 시간대별 절대 인원이 아니라 상대 비교로만 사용하세요.
- 시간대별 실측이 필요하면 해당 시각에 이 스크립트를 다시 실행해 그 시각 행을 교체하십시오.
